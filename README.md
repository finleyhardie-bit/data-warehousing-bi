## Center Court Retail: NBA jersey sales data mart
Team project for a fictional client. We're building a dimensional data mart that combines a jersey retailer's online and in-arena sales into one source for reporting.

| Folder | Stage |
|---|---|
| [`01-proposal-and-star-schema/`](center-court-retail-data-mart/01-proposal-and-star-schema) | Business requirements, KPIs and the star schema design |
| [`02-source-database/`](center-court-retail-data-mart/02-source-database) | Normalized (3NF) source database |
| [`03-etl/`](center-court-retail-data-mart/03-etl) | Extract, sentinel, lookup and validation scripts |
| [`04-analysis/`](center-court-retail-data-mart/04-analysis) | Analysis report for executives |
| [`05-presentation/`](center-court-retail-data-mart/05-presentation) | Final presentation |

> Not to be confused with my INFO 3100 NBA *player stats* analysis in [python-data-analysis](https://github.com/finleyhardie-bit/python-data-analysis).

**Tools:** SQL Server, T-SQL, SSIS, dimensional modeling
